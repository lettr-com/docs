---
title: Update a contact
openapi: PATCH /audience/contacts/{contactId}
---

Partially update a contact. If no fields are provided the contact is returned unchanged. Every key in `properties` must already be defined with [create a property](/api-reference/audience/create-a-property); an unknown key returns `422` and nothing is changed. Requires the `audience:write` scope and is blocked for sandbox API keys.
