---
title: Create a contact
openapi: POST /audience/contacts
---

Create a single contact. If `double_opt_in` is provided the contact is created in `unverified` status and receives a confirmation email — they become `subscribed` only after clicking the confirmation link. Every key in `properties` must already be defined with [create a property](/api-reference/audience/create-a-property); an unknown key returns `422` and the contact is not created. Requires the `audience:write` scope and is blocked for sandbox API keys.
